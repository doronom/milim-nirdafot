# מסע המילים — Component Sheet (All States)

### 1. WordCard / Headword Target
- **Default:** רקע כהה מוגבה (`#131c31`), מסגרת כחולה עדינה (`#0ea5e9`), טיפוגרפיה 28px ללא ניקוד, כפתור רמקול SVG משולב.
- **Guest State (מילה אורחת):** תג סגול ייעודי בפינה העליונה `תחנה קודמת · חזרה` עם אייקון סנכרון / סביבון.

### 2. OptionCard (Pick the Synonym)
- **Default:** רקע `#131b2e`, מסגרת `#2a3754`, טקסט לבן 20px, מספר סידורי קטן בפינה.
- **Hover/Touch:** רקע `#1e293b`, גבול `#0ea5e9` בעוצמה קלה.
- **Correct State:** מסגרת ירוקה זוהרת `#22c55e`, אייקון וי מעוצב, באדג' `+25 XP` מונפש.
- **Wrong State (חדש):** רעד אופקי (Shake 300ms), גבול אדום `#ef4444`, אייקון X, והדגשה בו-זמנית של התשובה הנכונה.

### 3. DragChip & DropZone (Drag Pairs)
- **Chip Idle:** רקע `#131b2e`, גבול `#2a3754`, אייקון גרירה 6 נקודות.
- **Chip Dragging:** הרמה (`scale(1.05)`), מסגרת כחולה מקווקוות זוהרת.
- **DropZone Active:** גבול מקווקו תכלת `#0ea5e9`, טקסט "שחרר כאן".
- **Matched Pair:** רקע ירוק עמוק עם גבול `#22c55e`, אייקון קישור נעול.
- **Wrong Return:** גבול אדום מהבהב, טקסט "לא מתאים", וחזרה אלסטית לטור המקורי.

### 4. StarRating & End-of-Level
- **3 Stars (מושלם):** כל 3 הכוכבים זוהרים בזהב (`#f59e0b`), תג "מדבקת אספנות נדירה".
- **2 Stars (טוב מאוד - חדש):** 2 כוכבים ראשונים מוארים, כוכב 3 מוצלל (`#334155`), "עוד קצת תרגול לציון מושלם!".
- **1 Star (הושלם בהצלחה - חדש):** כוכב ראשון מואר, 2 כוכבים מוצללים, עידוד להשלמת אתגר התחנה.

### 5. UI Utility Components
- **SpeakerButton:** כפתור SVG איכותי (רמקול מעוצב) במקום אימוג'י.
- **StreakFreezeBadge:** מגן כחול קרחוני עם פתית שלג SVG מלוטש במקום אימוג'י.
- **GuestBadge:** תג סגול אלגנטי `מילה אורחת` לשינון מרווח.
- **MascotBubble ("מצפוני"):** מצפן הרפתקאות מקורי עם הבעות (ניטרלי, שמח, חושב).
